☠️ Thousand Sunny — DevOps Raspberry Pi 5

Self-hosted Ubuntu Server (arm64) on a Raspberry Pi 5 (8GB), managed declaratively via Git from NixOS.

"The self-hosted One Piece is real!" — Public HTTPS from a student dorm with zero open router ports.

🧭 Grand Line Navigation (Traffic Flow & Isolation)

Internet (HTTPS 443) -> Tailscale Funnel -> Caddy (127.0.0.1:8080) -> Isolated Docker Networks
  • Zoro (UFW Firewall): Guards the hull by blocking all incoming dorm LAN ports except SSH (22/tcp).
  • Nami (Tailscale Funnel + Caddy): Navigates around dorm CGNAT and blocked ports, terminating public TLS and routing paths to internal containers.
  • Franky (Docker Hygiene): Maintains the ship with pinned image versions, JSON log rotation, isolated internal: true database networks, and untracked .env secrets.
